# Multipurpose Cleaning System

## Overview

The Multipurpose Cleaning System is a prototype developed during my
12th standard to combine multiple household and outdoor cleaning
functions into a single machine.

The project was selected for a national-level science exhibition in
New Delhi under INSPIRE Award MANAK.

## Key Features

- Floor dust collection
- Rotating sponge-based floor cleaning
- Flexible tube for slab cleaning
- Extendable roof-cleaning mechanism
- Brush attachment for removing roof dust
- Grass-cutting attachment
- Dust collection after grass cutting
- LED light for low-light operation
- Battery-powered operation
- Solar charging support
- Ability to perform multiple cleaning operations

## Motivation

Conventional cleaning tasks often require different tools for floors,
roofs and outdoor areas. This prototype was developed to explore
combining several cleaning functions into one portable system.

## Working Principle

The machine uses different mechanical attachments for different
cleaning operations.

For floor cleaning, the system collects dust while a rotating cleaning
mechanism assists with surface cleaning.

An extendable cleaning attachment is provided for elevated surfaces.

For garden maintenance, a rotating cutting attachment can be used,
while the dust-collection mechanism assists in collecting loose
material.

## Power System

The prototype is battery operated and includes provision for
solar-assisted charging.
